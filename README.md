# 💻 Aplicações com C# | Windows Forms

> Repositório dedicado ao desenvolvimento de aplicações desktop utilizando C# e Windows Forms, com foco em Programação Orientada a Objetos (POO) e boas práticas de desenvolvimento.

---

## 📌 Sobre o Projeto

Este repositório reúne exercícios, exemplos práticos e aplicações desenvolvidas durante a disciplina de Linguagem de Programação II (LP2).

O foco principal está na construção de aplicações com interface gráfica (GUI), utilizando o framework Windows Forms no ambiente Visual Studio, aplicando conceitos fundamentais de orientação a objetos.

---

## 🎯 Objetivos de Aprendizado

- Aplicar conceitos de Programação Orientada a Objetos (POO)
- Desenvolver aplicações com interface gráfica (GUI)
- Trabalhar com eventos e componentes visuais
- Estruturar projetos com separação de responsabilidades
- Praticar boas práticas de desenvolvimento em C#

---

## 🧠 Tecnologias Utilizadas

- C#
- .NET Framework
- Windows Forms
- Visual Studio

---

### 🖥️ Funcionalidades Desenvolvidas
- Criação de interfaces gráficas com Windows Forms
- Manipulação de eventos (cliques, inputs, validações)
- Implementação de lógica orientada a objetos
- Integração entre interface e lógica de negócio

---

### 📈 Evolução
